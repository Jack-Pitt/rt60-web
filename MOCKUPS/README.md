# RT60 — design mockups

SVG mockups for the header redesign + app icon. Open any of them in
**Safari** (best preview — renders SVG with system fonts) or **Preview**
on macOS. The headers mock the iPhone header bar at ~2× density on the
real `--color-bg` canvas.
